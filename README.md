The project serves as a local mindmapping tool and is under continuous development.

LocalPad is an offline-first, browser-based mind-mapping tool built on React and TypeScript with no backend or cloud dependency. It renders a spatial graph of nested cards and edges on an infinite canvas, backed by IndexedDB persistence, undo/redo, quadtree viewport culling, and hand-rolled Bezier edge routing. Everything — theming, import/export to JSON and Markdown, attachments, and cross-map references — runs entirely client-side, so it works on any modern browser on Windows, Linux, and iOS.
